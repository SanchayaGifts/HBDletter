# 💌 Aesthetic Birthday Love Letter Website

A romantic, interactive Birthday Wishes Website built using **pure HTML5, CSS3, and vanilla JavaScript**.

This website provides a realistic experience of receiving a romantic love letter, complete with:
- **Scene 1**: 3D envelope with a realistic wax seal and heartbeat pulse animation.
- **Scene 2**: Smooth envelope opening and realistic 3D paper emergence.
- **Scene 3**: Cream stationery paper unfolding with pressed dried roses, vintage postage stamp, and handwritten message reveal.
- **Scene 4**: Romantic background music with play/pause controls and automatic Web Audio API fallback.
- **Scene 5**: Final glowing 3D heart surprise with an emotional closing message.

## ✏️ How to Customize

All text can be customized directly in `index.html`:
1. **Recipient Greeting**: Edit line 173 (`To My Favourite Person, ♡`)
2. **Sender Signature**: Edit line 228 and line 282 (`[YOUR NAME] ♡`)
3. **Date**: Edit line 164 (`October 25, 2026`)
4. **Letter Body**: Edit paragraphs inside `<div class="letter-paragraphs">`
5. **Background Music**: Replace `love-song.mp3` with any MP3 of your choice.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in Google Chrome or run with VS Code Live Server.
3. Tap the envelope to experience the opening sequence!
